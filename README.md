# Módulo de Programación en C — 1º DAW

Repositorio de prácticas, algoritmos y ejercicios en lenguaje C organizados por temas y bloques de contenidos.

## 📁 Estructura del Repositorio

### Tema 1: Introducción a la Programación
- **`01_operadores_1/`**: Entrada/salida básica y operaciones elementales.
- **`02_operadores_2/`**: Expresiones lógicas y relacionales sin condicionales.
- **`03_casting_random/`**: Conversión de tipos implícita/explícita y generación de pseudoaleatorios.
- **`04_strings/`**: Lectura segura, longitud y funciones estándar de `<string.h>`.
- **`05_entregable_conversor/`**: Biblioteca modular de conversión entre bases numéricas (Binario, Octal, Decimal).

### Tema 2: Programación Estructurada
- **`01_condicionales/`**: Estructuras de selección `if`, `if-else` y `switch-case`.
- **`02_bucles/`**: Estructuras iterativas `for`, `while` y `do-while`.
- **`03_funciones/`**: Prototipos, ámbitos de variables y modularidad.
- **`04_punteros/`**: Operadores `&`, `*`, paso por referencia y puntero doble.
- **`05_arrays/`**: Vectores estáticos, matrices multidimensionales y gestión dinámica con `malloc`/`calloc`/`free`.

## 🛠️ Entorno de Trabajo
- **Sistema Operativo:** Ubuntu en WSL2
- **Compilador:** GCC (`build-essential`)
